# Healthcare Patient Analysis

## Project Overview
This project analyzes healthcare patient data using Python, SQL, and Power BI to identify patient demographics, disease trends, treatment costs, hospital performance, and recovery patterns. The project provides business insights through interactive dashboards, SQL analysis, and automated reporting.
